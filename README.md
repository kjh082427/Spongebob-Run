# 🧽 SpongeBob Run

스폰지밥 친구들이 달리는 러닝 게임입니다. 장애물을 점프로 넘고, 슬라이드로 피하며 최대한 멀리 달려보세요!

## 설치

**따로 설치할 것은 없습니다.** HTML / CSS / JavaScript로만 만들어져 있어서 웹 브라우저(Chrome, Edge, Firefox 등)만 있으면 됩니다.

> 처음 한 번은 인터넷 연결이 필요합니다. (Google Fonts의 `Jua` 글꼴을 불러옵니다. 연결이 안 되면 기본 글꼴로 표시됩니다.)

## 실행 방법

### 방법 1. 파일 바로 열기 (가장 간단)

1. 이 저장소를 내려받습니다.
   ```bash
   git clone https://github.com/kjh082427/Spongebob-Run.git
   ```
   (또는 GitHub 페이지에서 **Code → Download ZIP** 후 압축 해제)
2. 폴더 안의 `index.html`을 더블클릭해서 브라우저로 엽니다.

### 방법 2. 로컬 서버로 실행 (선택)

터미널에서 폴더로 이동한 뒤 아래 중 하나를 실행하고, 브라우저에서 `http://localhost:8000`에 접속합니다.

```bash
# Python이 설치되어 있다면
python3 -m http.server 8000

# Node.js가 설치되어 있다면
npx serve
```

## 조작법

| 키 / 동작 | 설명 |
|---|---|
| `←` `→` | (홈 화면) 캐릭터 선택 |
| `Space` | (홈 화면) 게임 시작 / (게임 중) 점프 — **한 번 더 누르면 2단 점프** |
| `↓` (누르고 있기) | 슬라이드 — 위쪽 장애물 아래로 통과 |
| `Space` / 클릭 | (게임 오버 후) 홈 화면으로 돌아가기 |
| 마우스 클릭 | 홈 화면에서 캐릭터 카드, 시작 버튼 선택 |

## 게임 규칙

- 체력(HP)은 **2칸**이며, 장애물에 부딪히면 줄어듭니다. 0이 되면 게임 오버!
- 피격 직후에는 잠시 무적 상태가 됩니다.
- 시간이 지날수록 달리는 속도가 점점 빨라집니다.
- 최고 기록은 브라우저에 자동 저장됩니다.
- 플레이 가능한 캐릭터: 스폰지밥, 뚱이, 징징이, 집게사장, 다람이
